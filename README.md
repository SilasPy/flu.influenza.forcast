# FluCast: Short-Term Influenza Forecasting

## Research Question

Can recent weekly influenza activity be used to predict national influenza activity one week ahead?

## Initial Goal

This project will compare simple forecasting methods using public influenza surveillance data.

The first models will include:

1. Last week's value
2. A three-week moving average
3. A recent-trend forecast
4. Simple linear regression

## Why This Matters

Short-term influenza forecasts may help researchers and public-health professionals anticipate changes in disease activity.
